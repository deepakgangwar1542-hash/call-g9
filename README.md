# Call Severity Triage Assistant (MVP) - GLA University B.Tech project

## Setup (ek baar)
    pip install -r requirements.txt
Dataset pehle se `data/raw/` me hai (STATS19 2023 collisions, 104,258 rows).

## Run order
    python step1_explore.py      # Step 3: dataset explore (SRS Section 3 ke numbers)
    python step2_clean.py        # Steps 4-6: cleaning + target + 5 features
    python step2_clean.py --include-after-sep17  # sensitivity dataset; writes clean_2023_all.csv
    python step3_train_eval.py   # leak-free CV selection, one final test, reports/figures, best model save
    python -m pytest -q          # MVP + Phase 1 regression tests
    streamlit run app.py         # Steps 13-15: prediction pipeline + UI + call logging (calls.db)

Settings: `common.py` me K_DEFAULT (shift capacity). The default cleaned data excludes records on/after 17-Sep-2023; the explicit alternate command above produces the all-rows sensitivity dataset.

## Sprint I (27 Sep) status — MVP done
| SRS ID | What | Where |
|--------|------|-------|
| FR-1.1 | Enter the five call conditions | `app.py` dispatcher form, options from `common.py` |
| FR-1.2 | Reject incomplete entry, naming missing field(s) | `predict.validate()` -> red error in UI, nothing stored |
| FR-2.2 | High risk / Low risk flag | `predict.predict_call()` with threshold from `models/best_model_meta.json` |
| FR-2.4 | Level 0 fallback flag labelled as estimate | `predict_call()` catches model failure -> `Level0-fallback` |
| FR-3.2 | Precision@K for a shift (K = dispatches sent) | `db.shift_precision_at_k()` -> supervisor tab |
| FR-3.3 | Zero-dispatch guard (no divide-by-zero) | message shown instead of a number |
| NFR-1 | Flag within 2 s | measured in `test_mvp.py` (runs in ~1.4 s incl. logging) |
| NFR-3 | Log call ID, inputs, confidence, model version per call | `db.log_call()` -> SQLite `calls.db` (auto-created) |

Model result: generated by `step3_train_eval.py`; see `reports/model_comparison.csv`, `reports/paired_difference.csv`, `reports/sep17_sensitivity.csv`, and `reports/phase1_summary.md`. Precision@300 is averaged over 20 deterministic tie-breaks, and model-vs-baseline claims use a paired bootstrap CI on the difference.

UI: dark control-room theme in `theme.py` + `.streamlit/config.toml`.

## Landing page

The static project landing page is in `docs/`. Preview it locally from the repository root:

    python -m http.server -d docs 8000

Open `http://localhost:8000`. To publish with GitHub Pages, open **Settings → Pages**, select branch `main`, choose the `/docs` folder, then save. The page's simulation uses a simplified speed/light lookup and is not the trained model.
