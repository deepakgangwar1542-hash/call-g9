The problem

Response capacity is fixed. Calls are not.

Each shift has a limited number of enhanced responses. During an incoming call, the dispatcher often has only road type, speed limit, weather, light, and junction detail to work with.

Enhanced response / shift 7 / 12 slots

Rank calls consistently within each force's quota, then keep human judgement in the loop.
